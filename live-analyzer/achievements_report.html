Core Technologies Utilized

Backend: Python 3.11, FastAPI, Uvicorn, SQLAlchemy, SQLite
Integrations: official kiteconnect SDK wrapper
Financial Calculations: numpy-free Newton-Raphson & Bisection XIRR calculations
Scheduler: APScheduler BackgroundScheduler (daily cron triggers)
Frontend: React 19, Vite, Recharts, Lucide Icons
Security: Cryptography (Fernet symmetric encryption), PyJWT, Bcrypt
